## 📁 Website Architecture

- `index.html` — Homepage featuring the Since 1992 heritage, introduction to Dr. Sudhir Lohia, service pillars, medicine dispensing principles, online care workflow, why choose us, and quick consultation modal.
- `about.html` — About Lohia's Homoeopathy, history since 1992, Dr. Sudhir Lohia's background and constitutional philosophy.
- `services.html` — Dedicated, responsible details on:
  1. Homeopathic Consultation
  2. Homeopathic Medicines
  3. Online Consultation
  4. Healthcare Guidance
- `online-consultation.html` — Step-by-step remote consultation workflow, patient enquiry form with direct WhatsApp dispatch (`+91 942 216 1321`), privacy safeguards, and patient FAQs.
- `contact.html` — Click-to-call, mailto, interactive Google Maps embed of Pashmina Waterfront on Old Madras Road, Battarahalli, and contact inquiry form.
- `css/style.css` — Responsive design system, CSS variables, accessible focus states, mobile drawer, modal styles.
- `js/main.js` — Mobile drawer toggle, interactive modal dialog, form validations, honeypot spam protection, structured WhatsApp URL generator.
- `sitemap.xml` & `robots.txt` — Search engine indexation setup with local SEO for Bengaluru.
- `vercel.json` — Production deployment configuration with clean URLs and strict security headers.
